# Data Collection and Processing

Data was collected from two Google Forms:
- **Form A**: https://forms.gle/MheNAMAtfrodNCwV8
- **Form B**: https://forms.gle/oSvxRPaqD5ZUFTZR9

## Data Processing
The two csv files from the forms (in raw/) were merged into a single dataset, in notebooks/merged_eval.xlsx. The merged Excel file was augmented with:
- Statistical calculations
- Color coding for visualization
- **Note**: The original content of responses was not altered

## Usage
The processed data was used in the notebook scripts to generate graphs and visualizations for the dissertation analysis.
